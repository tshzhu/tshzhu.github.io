# tshzhu.github.io

Personal Homepage generated by [jemdoc+MathJax](https://github.com/wsshin/jemdoc_mathjax).

## Windows workflow

Install Python 3 and make sure `python` is available in CMD. From this
repository directory, double-click `build.cmd` or run:

```bat
build.cmd
```

The script compiles all `.jemdoc` source files using `mysite.conf`.

`jemdoc.py` expands the wildcard itself on Windows (where CMD does not expand
`*.jemdoc`) and always writes generated HTML as UTF-8. The same `jemdoc.py`
implementation also remains compatible with Linux/WSL if needed.

After checking the generated HTML, synchronize the site with Git in the usual
way:

```bat
git add .
git commit -m "Update homepage"
git push
```
