# tshzhu.github.io

Personal Homepage generated by [jemdoc+MathJax](https://github.com/wsshin/jemdoc_mathjax).

## Windows workflow

Install Python 3 and make sure `python` is available in PowerShell or CMD. From
this repository directory, build all pages with either:

```powershell
.\build.ps1
```

or, in CMD:

```bat
build.cmd
```

The equivalent direct command is:

```powershell
python jemdoc.py -c mysite.conf *.jemdoc
```

`jemdoc.py` expands the wildcard itself on Windows (where the shell does not
expand `*.jemdoc`) and always writes generated HTML as UTF-8. This keeps the
same command usable from Linux, CMD, and PowerShell, including pages containing
Chinese or other non-ASCII text.

After checking the generated HTML, synchronize the site with Git in the usual
way:

```powershell
git add .
git commit -m "Update homepage"
git push
```
